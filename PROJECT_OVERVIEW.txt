🚀 QUICK START GUIDE
───────────────────────────────────────────────────────────────────────────────

STEP 1: Open Application
   → Open HTML/sigin.html in any modern browser
   → You'll see the login page with animations

STEP 2: Create Account
   → Click "Sign up" link
   → Complete 3-step registration
   → View confirmation page

STEP 3: Access Dashboard
   → Proceed to main dashboard
   → See 5 pre-loaded students
   → View statistics cards

STEP 4: Explore Features
   → Add new student via "+ Add Student" button
   → Edit existing student
   → Delete student with confirmation
   → Search by name, email, or phone
   → Filter by category/status

STEP 5: Navigate Pages
   → Use sidebar to navigate
   → Try Education page (grades, courses, certs)
   → Check Finance page (transactions, expenses, reports)
   → View Contact page (staff, departments, support)
